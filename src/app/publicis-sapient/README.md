# Publicis Sapient Website Clone

This is a modern, responsive website clone inspired by the Publicis Sapient website design. The website features a professional design with smooth animations, mobile responsiveness, and modern UI/UX practices.

## Features

### 🎨 Design Features
- **Modern Hero Section** with gradient background and floating cards
- **Responsive Navigation** with mobile hamburger menu
- **Service Cards** with hover animations
- **About Section** with statistics and company information
- **Client Showcase** section
- **Contact Form** with validation
- **Professional Footer** with social links

### 📱 Responsive Design
- Mobile-first approach
- Tablet and desktop optimized
- Smooth mobile navigation
- Touch-friendly interface

### ⚡ Performance Features
- Lazy loading modules
- Optimized CSS with SCSS
- Smooth scroll animations
- Efficient component structure

## Components

### Main Component
- `PublicisSapientComponent` - Main landing page component

### Sections
1. **Navigation** - Fixed header with smooth scroll
2. **Hero** - Eye-catching introduction with call-to-action
3. **Services** - Grid layout showcasing company services
4. **About** - Company information with statistics
5. **Clients** - Client showcase section
6. **Contact** - Contact form and information
7. **Footer** - Links and company information

## Technologies Used

- **Angular 15+** - Frontend framework
- **SCSS** - Advanced CSS preprocessing
- **Material Icons** - Icon library
- **TypeScript** - Type-safe JavaScript
- **Responsive Design** - Mobile-first approach

## Styling

The website uses a modern color scheme:
- Primary Blue: `#0066cc`
- Secondary Blue: `#004499`
- Accent Blue: `#00aaff`
- Text Colors: Various grays for hierarchy
- White and light backgrounds for contrast

## Animations

- Floating cards in hero section
- Hover effects on service cards
- Smooth scroll navigation
- Mobile menu transitions
- Button hover effects

## Getting Started

1. Navigate to the website: `http://localhost:4200/publicis-sapient`
2. The website will load with the Publicis Sapient clone
3. Test responsive design by resizing the browser
4. Test mobile menu on smaller screens

## Customization

To customize the website:

1. **Colors**: Update the SCSS variables in the component styles
2. **Content**: Modify the TypeScript arrays for services and clients
3. **Layout**: Adjust the grid layouts in the SCSS
4. **Animations**: Modify the keyframes and transitions
