# EaseOnTech - Software Development Company Website

This is a modern, responsive website for EaseOnTech, a professional software development company. The website showcases our services, portfolio projects, client testimonials, and provides a comprehensive platform for potential clients to learn about our capabilities and get in touch.

## Features

### 🎨 Design Features
- **Modern Hero Section** with gradient background and floating cards
- **Responsive Navigation** with mobile hamburger menu
- **Service Cards** with hover animations showcasing our development services
- **Portfolio Section** displaying featured projects with technology stacks
- **Testimonials Section** with client feedback and ratings
- **About Section** with company statistics and technology stack
- **Contact Form** with service selection and project details
- **Professional Footer** with portfolio links and social media

### 📱 Responsive Design
- Mobile-first approach
- Tablet and desktop optimized
- Smooth mobile navigation
- Touch-friendly interface

### ⚡ Performance Features
- Lazy loading modules
- Optimized CSS with SCSS
- Smooth scroll animations
- Efficient component structure

4. Test mobile menu on smaller screens

## Customization

To customize the website:

1. **Services**: Modify the `services` array in the TypeScript component
2. **Portfolio**: Update the `portfolio` array with your projects
3. **Testimonials**: Add client feedback to the `testimonials` array
4. **Statistics**: Update the `stats` array with your company metrics
5. **Technology Stack**: Modify the `technologies` array
6. **Colors**: Update the SCSS variables in the component styles
7. **Layout**: Adjust the grid layouts in the SCSS
